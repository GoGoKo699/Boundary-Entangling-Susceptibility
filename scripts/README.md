# Scripts

## Core figures

`scripts/figures/` contains one standalone plotting entry point for each of the four composite paper figures. Together they regenerate the six Python panels from the canonical tables under `data/processed/core_figures/`.

## Full studies

Load-bearing simulation and analysis scripts are grouped by their scientific stage under:

- `studies/checkpoint_04/scripts/`
- `studies/checkpoint_05/scripts/`

The study READMEs state which files are complete simulators, analysis drivers, or validation tools.

# F-01: source-bound supporting exports

## Decision and scope

The repair regenerates exactly the retained 30 rank-four endpoints and 15
primary all-probe stencil rows. It does not copy the schema-mismatched 45-row
consolidated table, rerun simulation, alter reference spectra, change the core
four figures, or generate a new bootstrap. The design was communicated before
the record-only reconstruction. The required computation is below one CPU
second and needs no large-study replay.

The two defective compact files were copied byte-for-byte using an explicit
patch into `studies/checkpoint_04/results/historical/pre_full_sanity_01/` and
checked against their blobs at audit commit
`897dba9926583d12bcaacb214d62a5652c1ba8e1`. Their README labels them rejected
historical exports and records SHA-256 values. Their unexplained provenance is
not guessed. All bytes under `audits/full-sanity-01/` remain untouched by this
repair.

## Defined replacement

`scripts/analysis/reproduce_supporting_records.py` reads the root archive
directly, verifies the exact hashes of the primary and independent original
compressed row members plus the consolidated interval source, and selects
confirmatory rank-four replaced states at p=.08 and .24. Each run/family uses
its own (n,tau) cells supported at both rates. It averages rows within cells,
takes high minus low, then weights the supported cells equally.

The response is chi2, normalized linear-entropy change without input-purity
division. D/(D-1) is evaluated in each size cell, never after pooling sizes.
These endpoints intentionally differ in both observable and comparison-support
rule from current Figure 1. Each primary all-probe decomposition uses exactly
the endpoint estimator and records both raw and dimension-weighted purity
shifts. `intervention_comparison_support.csv` enumerates actual eligibility,
cell weights and factors. `supporting_records_manifest.json` specifies source
hashes, exact coefficients, filters, uncertainty status and generated hashes.

The `archived_ci_*` columns retain the consistent original consolidated
intervals only after checking their corresponding points against original
rows. The new column names and per-row status explicitly distinguish archived
uncertainty from fresh calculations. The documented older 4,000-draw routine
resamples trajectories and omits undefined cells within a draw. It is not the
current Figure 1 full-support rejection procedure. No historical invocation,
saved extension draw vectors, simultaneous confidence or exact small-sample
coverage is claimed. These intervals remain qualified supporting diagnostics.

`docs/EXTENDED_RESULTS.md` and the results README clarify this scope, historical
status, and the separate dimension-weighting/variable-support limitations of
the gate-space extension. This component makes no stronger empirical claim.

## Verification actually performed

Environment: existing clean pinned audit virtual environment, Python 3.12.13.
The exporter itself uses Python standard-library code only, no original
scientific estimator or simulator imports. It is deterministic and has no RNG
seed. Commands from the repository root:

```bash
/workspace/scratch/0174ee249694/audit-venv/bin/python scripts/analysis/reproduce_supporting_records.py --output repairs/full-sanity-01/supporting_exports --check
/workspace/scratch/0174ee249694/audit-venv/bin/python -m pytest -q tests/test_supporting_exports.py
```

The first completed record check matched all four generated files byte-for-byte,
all 30 endpoints and all 15 decompositions. Maximum rowwise stencil error was
1.4224732503009818e-16; maximum archived endpoint discrepancy was
5.551115123125783e-17, both below the absolute 2e-12 tolerance. All replacement
points also match the independently reconstructed frozen audit table.

The focused tests separately use exact decimal-rational row contractions with
gate-invariant-derived coefficients, followed by rational cell means and
equal-cell contrasts. They compare every endpoint and every primary stencil
component, check current coefficient metadata, preserve historical hashes,
and reject injected coefficient, original-member and current-export defects.
This is independent of the exporter's floating-point estimator but still
shares original observations and the published response identity. It is not
independent physical simulation or a fresh uncertainty analysis. Root-level
repair logs record the final test count and full-suite verification.

## Outcome

The retained supporting points now have a deterministic source-to-export path;
all exact contributions reconstruct their stated endpoints. Original bad
exports remain identifiable and recoverable. Their historical discrepancy
cause is still unknown. Missing schematics, attribution and other audit
findings are outside this component and are not silently declared resolved.

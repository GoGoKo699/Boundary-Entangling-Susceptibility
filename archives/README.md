# Archived binary packages

The complete Checkpoint 04 and Checkpoint 05 handover ZIP files are intentionally not committed to ordinary Git history. Before public release they should be attached to a versioned GitHub Release or deposited in a research archive. Their source hashes and data policy are documented under `provenance/` and `docs/DATA_POLICY.md`.

Historical split-flow and Aubry–André archives are not part of the active scientific workflow.

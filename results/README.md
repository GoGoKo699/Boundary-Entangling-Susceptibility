# Results index

The root results layer provides a compact claim-level index. Detailed tables are kept next to the study that generated them.

- `core_claims.csv`: headline claims, evidence type, and scope.
- `studies/checkpoint_04/results/`: intervention, architecture/probe, and exact response-stencil tables.
- `studies/checkpoint_05/results/`: large-size, transition, boundary-code, and paired-intervention tables.
- `data/processed/core_figures/`: the exact rows plotted in the six core Python panels.

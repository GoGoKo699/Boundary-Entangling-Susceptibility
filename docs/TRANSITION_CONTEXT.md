# Relation to the monitored transition

Quarter-partition tripartite information places the high-size crossing near $p\simeq0.27$ in the package convention, where $p$ is the measurement probability per site per complete two-sublayer brickwork cycle. The fixed-spectrum response remains negative on both sides but weakens above the crossing. It is therefore transition-sensitive but is not an order parameter.

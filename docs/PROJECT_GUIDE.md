# Project guide

Read this project directly in GitHub. The pages use ordinary Markdown, with the approved color palette confined to scientific figures.

## Understand the result

Start with the [scientific story](SCIENTIFIC_STORY.md), then follow the [nine main questions and appendix answers](DIALOGUE_REPORT.md). The [question map](DIALOGUE_QUESTION_MAP.md) provides a shorter index. The [figure gallery](../figures/README.md) links each panel to its numerical table.

## Check the argument

The [notation](NOTATION.md), [exact theory](THEORY.md), and [claim-and-evidence map](CLAIM_EVIDENCE_MAP.md) distinguish identities from observations. The [methods](NUMERICAL_METHODS.md), [evidence reassessment](EVIDENCE_REASSESSMENT.md), and [limitations](SCOPE_AND_LIMITATIONS.md) specify the comparison populations and inferential boundaries.

## Reproduce the evidence

Use the [reproduction guide](REPRODUCTION.md) and [code map](CODE_MAP.md). A figure redraw reads canonical tables. A record replay recalculates quantities from stored observations. Bootstrap regeneration follows the adopted recipe. A new simulation campaign generates new physical trajectories. These are different operations.

The [data policy](DATA_POLICY.md), [record manifest](../data/record_bundle_manifest.json), and [reproducibility limits](REPRODUCIBILITY_LIMITS.md) describe what is included. Figure 1's [current uncertainty calculation](FIGURE1_UNCERTAINTY.md) is reproducible; its missing historical bootstrap has not been recovered.

## Before writing the manuscript

The manuscript remains the final step. The repository must first contain every retained scientific definition, proof, method, evidence table, figure source, and attribution required for it.

The existing numerical figure panels are tracked. The external composite-figure schematics still require the author's actual editable sources; no unseen Overleaf layout has been recreated. This remains an open asset-completion item. The equation-level entanglement-feature connection is now integrated into the authoritative [related-work account](RELATED_WORK.md) and [theory](THEORY.md), with established machinery distinguished from the empirical comparisons.

The [full audit](../audits/full-sanity-01/REVIEW.md) is an immutable assessment of the pre-repair baseline. Its [repair record](../repairs/full-sanity-01/SUMMARY.md) identifies corrected supporting tables, validation and wording, and remaining limitations. An old finding should be read at its stated baseline, not silently treated as either erased or still unresolved.

The [citation record](../CITATION.cff), [license status](../LICENSE_STATUS.md), and [public-release checklist](../provenance/PUBLIC_RELEASE_CHECKLIST.md) remain separate. No public hosting or new permission grant is implied.

## Research history

The [research history](RESEARCH_HISTORY.md), [run history](RUN_HISTORY.md), and [provenance](../provenance/README.md) are available for tracing sources. They are not prerequisites for understanding the current study.

# Reproduction

## A. Redraw the current approved panels

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-reproducible.txt
pip install -e .
pytest -q
python verify.py
python reproduce.py --core-figures
```

The command checks a fresh staging directory for exactly six PDF/PNG/SVG triples, then copies them into `reproduced_figures/`. It does not recursively delete existing user directories. `--output /path/to/outputs` selects another destination.

The current Figure 4 distance panel contains the original means and intervals, with the historical exponential curve and its annotation removed after author approval. Its plotting source requires the two original CSVs only; `figure_04_distance_fit.json` remains historical analysis input, not active plotting input. Figures 1–3 and the Figure 4 contrast panel are unchanged. See [the approved baseline and caption](FIGURE_BASELINE.md).

All three formats are generated by the same plotting code. The original external PDF hashes in [the historical manifest](../provenance/figure_sha256.csv) describe the pre-revision Overleaf baseline and must not be mistaken for current-output hashes. Browser SVG text can use fallback fonts, whereas the PDF embeds its publication fonts.

## B. Recalculate estimates from stored trajectory records

Obtain the original Checkpoint 05 ZIP identified in [DATA_POLICY.md](DATA_POLICY.md), then run:

```bash
python scripts/analysis/reassess_evidence.py \
  --archive /path/to/entanglement_project_checkpoint_05.zip \
  --output reproduced_evidence --bootstrap 5000 --seed 2026090501
```

The script rejects an archive with the wrong SHA-256. It recalculates all 16 finite-size coefficients from 237,600 stored state records, replays the paired endpoints from 75,600 intervention records, computes new same-side/common-eligibility location checks, and produces model-residual and finite-size sensitivity tables. It records the member hashes, software versions, and seed.

New location intervals use fresh trajectory-cluster bootstrap samples. Finite-size model intervals reuse archived size-level bootstrap samples. The script imports no original checkpoint estimator. All newly introduced selection rules and model comparisons are explicitly post-hoc; they do not replace the original primary analyses. The [results directory](../results/evidence_reassessment/) records selected outputs.

The original ZIP is not yet available through a permanent repository-linked data deposit. A clone alone supports route A but not archive-based route B without obtaining that ZIP separately.

## C. Rerun circuit generation

The retained study source is under [Checkpoint 04](../studies/checkpoint_04/) and [Checkpoint 05](../studies/checkpoint_05/). The full circuit-generation campaign was not rerun in the evidence pass. Its complete data and environment requirements must be recovered with the original packages before claiming end-to-end simulation reproduction.

## What automated checks establish

CI installs the declared dependencies, runs unit and export tests, checks frozen numerical/structural expectations with `verify.py`, and regenerates all 18 outputs. Additional tests check that the approved distance panel preserves its original point and interval arrays and does not add a fitted curve. Generated outputs are workflow artifacts; normal CI does not commit to `main`.

CI does not rerun the external raw archive or independently validate all scientific interpretations. Frozen-value regression checks, stored-row reanalysis, and external replication are distinct. The [dialogue report](DIALOGUE_REPORT.md) preserves those distinctions throughout the scientific argument.

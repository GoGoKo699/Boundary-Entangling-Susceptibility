# Figures

`core_svg/` contains browser-ready vector renderings of the six author-reviewed Python panels used by the planned Letter. Their canonical numerical inputs are in `data/processed/core_figures/`, and the plotting scripts are in `scripts/figures/`.

The SVG files are compact GitHub display derivatives. The author-approved PDF hashes are recorded in `provenance/figure_sha256.csv`; accepted PDFs are intended for the first versioned release rather than ordinary source review.

`extended/` is reserved for robustness and transition-context figures beyond the four-figure main chain.

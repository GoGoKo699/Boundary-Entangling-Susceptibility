# Public release checklist

The scientific and reader-facing migration is complete on the default branch. The following administrative and archival steps remain before making the repository public.

- [ ] Choose a code license.
- [ ] Choose compatible data and figure licenses.
- [ ] Upload the complete Checkpoint 04 and Checkpoint 05 archives to a versioned GitHub Release or research-data repository.
- [ ] Record immutable asset URLs and SHA-256 hashes in `docs/DATA_POLICY.md`.
- [ ] Complete an independent specialist audit of the response-operator and stabilizer boundary-code theorems.
- [ ] Run the full clean-clone CI workflow after the raw-data links are added.
- [ ] Replace the provisional `CITATION.cff` metadata with the preprint DOI or arXiv identifier.
- [ ] Remove temporary migration branches created during repository construction.
- [ ] Confirm all README equations and SVGs render correctly in the public view.

No manuscript TeX or TikZ should be added during release preparation.
